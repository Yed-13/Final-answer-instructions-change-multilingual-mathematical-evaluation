# Final-answer instructions in multilingual mathematical evaluation

Experiment materials for study of final-answer instructions with Qwen2.5-7B-Instruct and Mistral-7B-Instruct-v0.3 in English, Chinese and Spanish.

Companion materials for “Final-answer instructions change multilingual mathematical evaluation: clause-level controls and extraction sensitivity”, submitted to *Language Resources and Evaluation*.

**Author and corresponding contact:** Zehao Li, Northeastern University, Boston, Massachusetts, USA; li.zehao5@northeastern.edu.

## Reproduce the reported analyses

Use Python 3.12 and install the analysis dependencies:

```bash
python -m pip install -r requirements.txt
python reproduce.py
```

This reads the saved responses, scores them with the two specified extraction rules, recomputes paired comparisons and renders the MGSM tables and figures into the ignored `manuscript/` build directory. It also verifies the original MGSM validation statistics using a separate aggregate calculation. A GPU and model downloads are needed for new generation, but the saved-response analyses run on a CPU.

| Stage | Questions | Requests | Location |
|---|---:|---:|---|
| MGSM controlled study | 250, including 100 format-control and 50 wording-control questions | 2,300 | `experiment/focused/` |
| MGSM exploratory follow-up | 100 development questions | 600 | `experiment/focused/followup-*` |
| MGSM clause-level validation | 136 questions outside development and technical-pilot subsets | 2,448 additional; 816 reused baselines | `experiment/revision/` |
| MSVAMP replication | 200 questions with all three conditions newly generated | 3,600 | `experiment/replication/` |

The four stages contain 8,948 analytical attempts. The 51-request initial technical pilot and 12 serial replay responses are kept separately. They are not added to the analytical denominators. Conditions, languages and models are paired within question; the request total is not an independent sample size.

`instructions.json` gives the complete language-specific instructions. Each call record additionally preserves its exact instruction and question, model, numerical reference, decoding seed and token budget. The call identifier joins the corresponding response text and termination status. Readable identifiers are used consistently across reused baselines. `model-versions.json` identifies the exact model files and backend release; `chat-template-*.txt` records model-native serialization.

## Results and outcome definitions

Generated CSV files in `audit/focused_study/`, `audit/revision_study/` and `audit/replication/` contain all cell counts and paired comparisons. `scored.jsonl` files contain item-level outcomes. The manuscript's MGSM validation tables are generated by `analysis/render_revision.py`; the replication tables are generated by `analysis/render_replication.py`.

Correct delivery is the proportion of requests yielding an accepted correct number. Extraction coverage is the proportion accepted by the evaluator; conditional correctness uses this accepted subset. Binary-completion bounds assign either binary label to every unscored request while retaining observed labels. For absent or incomplete responses those labels are hypothetical completions, not correctness judgements about an existing final answer. Human-adjudicated correctness is not measured. Strict scoring requires the entire suffix after the last `####` marker to be numeric; marker-line scoring uses the complete first line of that suffix. Neither scorer selects a number by matching it to the reference.

`examples/` contains complete paired response illustrations and a deterministic syntax diagnostic of the Mistral English minimal condition. Feature counts overlap and describe text syntax. They are not human annotation labels.

## Generate a replication

Download the pinned GGUF files identified in `model-versions.json` into `models/`, and use llama.cpp release b10936. The recorded hardware is an RTX 5080 with 16 GB VRAM. Start Qwen with its native template:

```bash
llama-server -m models/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf --alias Qwen/Qwen2.5-7B-Instruct -ngl 99 -c 16384 -np 4 --jinja --host 127.0.0.1 --port 8087
```

In a second terminal:

```bash
python run_generation.py --calls experiment/replication/calls.jsonl --output rerun/replication-responses.jsonl --model Qwen/Qwen2.5-7B-Instruct --execute
```

Then stop that server and start Mistral:

```bash
llama-server -m models/Mistral-7B-Instruct-v0.3-Q4_K_M.gguf --alias mistralai/Mistral-7B-Instruct-v0.3 -ngl 99 -c 16384 -np 4 --jinja --host 127.0.0.1 --port 8087
python run_generation.py --calls experiment/replication/calls.jsonl --output rerun/replication-responses.jsonl --model mistralai/Mistral-7B-Instruct-v0.3 --execute
```

The runner uses four concurrent requests, temperature 0, top-p 1, a requested seed of 20260913, a 512-token limit and disabled prompt-cache reuse. It resumes by call ID, retaining failed attempts. The original response files remain the basis of the reported results. Hardware and batching differences can change newly generated text.

The development follow-up is exploratory. The 136-question MGSM validation reuses restrictive baselines whose aggregates were known. MSVAMP conditions and extraction rules were frozen before generating any selected MSVAMP responses. Neither public benchmark is certified absent from model training. See `DATA_SOURCES.md` for input sources and permissions.
